## 🆕 Что нового в v3.2.2

За последние обновления мы переработали ключевые части программы.

### 🎯 Честная проверка точности

Раньше «Проверить точность» считала ΔE на тех же патчах, по которым строился
профиль — это **ошибка подгонки**, цифры всегда получались завышенно хорошими.

Теперь есть кнопка **«🎯 Честная точность (вне выборки)»**. Она делит ваши
измерения на две части: по одной строится профиль, на другой считается точность.
Профиль этих патчей **не видел** — значит, цифры честные.

Вы увидите **два числа**:

| Показатель | Что значит |
|---|---|
| **В выборке (завышено)** | Старая оценка, для сравнения |
| **Вне выборки (честно)** | Реальная точность профиля |
| **Ошибка подгонки** | Разница между ними — насколько профиль переобучен |

Обычно разрыв в 2–3 раза — норма. Если больше — увеличьте число патчей или смените бумагу.

К обеим кнопкам добавлена **справка «❓ Как читать ΔE»**: что значат числа,
какие значения считать приемлемыми для разных типов бумаги, что делать при
плохой точности.

### 🛠️ Основной сценарий надёжнее

- **Печать мишени** показывает реальные имена файлов (`chart_01.tif … chart_09.tif`)
  и их количество — раньше предлагалось напечатать один файл, которого не существовало.
- **Проверка точности и сравнение профилей** честно сообщают об ошибках: если
  `profcheck` не смог отработать — вы увидите понятное сообщение, а не «✅ Готово»
  с пустыми цифрами.
- **Сравнение двух профилей** переписано: теперь показывает **точность каждого
  профиля** и **охват цветов** через `iccgamut`.

### 💾 Данные больше не теряются

- В сборке EXE все настройки, профили, бэкапы и логи сохраняются в
  **`%APPDATA%\PrinterProfiler`** — постоянное место, не удаляется при выходе.
- Настройки и конфиг пишутся **атомарно**: даже при обрыве питания старый
  файл останется целым.

### 🗂️ Восстановление бэкапов из программы

Кнопка **«📦 Бэкапы»** — список архивов с датой и размером, восстановление
в один клик.

### 🎨 Интерфейс на любом масштабе

Размер окна считается в правильных единицах и корректно помещается при любом
DPI (150 %, 200 % и т.д.). На очень маленьком экране — честное предупреждение.

### 🧹 Меньше мусора

Логи подчищаются автоматически:

| Тип | Сколько хранится |
|---|---|
| Дневные (`logs/YYYY-MM-DD.log`) | последние **30** |
| Операционные (`profiles/logs/profile_*.log`) | последние **50** на папку |
| Crash-логи (`logs/crash/*.log`) | последние **10** |

Отчёты проверки точности получают **метку времени** в имени, старые подчищаются.
В каждом отчёте явно указано, что метрика — **ΔE2000** (CIEDE2000).

### 🔧 Множество мелких улучшений

- **Поле «патчи»** принимает только цифры 50–10000 — никакой тихой подмены.
- **Инструмент `printtarg`** больше не зашит на ColorMunki — указывается в конфиге.
- **Флаг `-h`** (двойная плотность) вынесен в настройку. По умолчанию **выключен**.
- **Ошибки прибора и ошибки измерения** разделены: для «прибор не найден» —
  инструкция по Zadig, для «измерение не завершено» — свои причины.
- **Рабочий поток** не обрывает запись файлов при выходе.
- **Конфиг мигрирует автоматически** — старые параметры дополняются, старый
  файл сохраняется как бэкап.
- **Ключи лицензий не затрагиваются**: делается резервная копия, сами ключи
  не изменяются.

## 📖 Что это

Argyll Printer Profiler — утилита для Windows 10/11, которая:

- 🎨 Автоматизирует профилирование принтера через ArgyllCMS
- 📄 Создаёт ICC-профили для конкретной бумаги, чернил и принтера
- 📊 Проверяет точность готового профиля (ΔE)
- 🆚 Сравнивает два профиля, чтобы выбрать лучший
- 💾 Делает резервные копии профилей
- 🔍 Проверяет подключение калибратора ColorMunki
- 🔄 Проверяет обновления автоматически
- 🔒 Работает по лицензии с привязкой к ПК

Всё локально, кроме проверки обновлений и активации ключа.

- Права администратора (для USB-прибора и драйверов)

## 🎨 Основной сценарий: профилирование

### Шаг 1. Подготовка

- Подключите принтер (включён, готов к печати)
- Подключите калибратор через USB
- Убедитесь, что ArgyllCMS установлен (путь в настройках)
- Убедитесь, что драйвер libusb-win32 установлен

### Шаг 2. Параметры профиля

В левой панели:

- **Шаблон** — выберите бумагу или оставьте «— свой —»
- **Принтер** — обычно определяется автоматически
- **Бумага** — латиницей, без пробелов (например, `LomondGlossy`)
- **Поверхность** — Glossy / Satin / Matte / Luster
- **Размер** — A4 / A3 / Letter / A2
- **Патчей** — 800 (стандарт), 1200+ (высокая точность)

> ⚠️ Патчей больше = точнее профиль, но дольше измерение. Начните с 800.

### Шаг 3. Проверка прибора

Нажмите **🔍 Проверить прибор**.

Ожидаемо: `✅ Прибор обнаружен` + 🟢 индикатор в шапке.

Если не найден → откроется окно со справкой Zadig.

### Шаг 4. Полный цикл

Нажмите **🔄 Полный цикл**.

Программа:

1. Генерирует мишень с 800 патчами (`targen`)
2. Печатает на принтере (`printtarg`)
3. Просит приложить спектрофотометр к каждому патчу (`chartread`)
   → появится жёлтый баннер **«Пауза»** → **► ПРОДОЛЖИТЬ**
4. Строит ICC-профиль (`colprof`)
5. Создаёт ZIP-бэкап (если включено)

**Время:** 20–60 минут в зависимости от принтера и патчей.
**Прерывание:** кнопка **⏹ Остановить** (можно дособрать через Resume).

### Шаг 5. Готово

В журнале:

```
✅ ICC-профиль: D:\PrinterProfiler\profiles\LomondGlossy\LomondGlossy.icc
```

Откройте папку **📂 Папка** или **🎨 Профили** — файл `.icc` там.

**Установка профиля в Windows:**
1. ПКМ по `.icc` → **Установить профиль**
2. Или: Параметры → Дисплей → Дополнительные параметры дисплея → Управление цветом

## ⚙️ Параметры профиля

### Шаблон

При выборе бумаги из списка Бумага / Поверхность / Размер / Патчи заполняются
автоматически. Если патчи правились вручную — они не перезапишутся.

### Принтер

- Загружается из системы (через `pywin32`)
- Кнопка ↻ — обновить список
- Если пусто → `pip install pywin32`

### Бумага

Название латиницей, без пробелов. Используется в имени папки, `.icc`-файла и лога.
Примеры: `LomondGlossy`, `EpsonPremium`, `A4_HP_Photo`.

### Поверхность

| Значение | Когда |
|---|---|
| `Glossy` | Глянцевая |
| `Satin` | Сатиновая |
| `Matte` | Матовая |
| `Luster` | Люстр (полуглянец) |

### Размер

A4 / A3 / Letter / A2 — должен соответствовать реальному листу в принтере.

### Патчей

Кнопки −50 и +50 или ручной ввод.

| Значение | Точность | Время |
|---|---|---|
| 200–500 | Быстро, грубо | 10–15 мин |
| **800** | **Стандарт** | **20–30 мин** |
| 1200–2000 | Высокая точность | 40–60 мин |
| 3000+ | Максимум | 1–2 часа |

> Если вручную поменяли патчи, а потом выбрали шаблон — патчи не перезапишутся.
> Появится подсказка «отличается от значения по умолчанию».

## ▶️ Операции

### 🔄 Полный цикл

`targen → printtarg → chartread → colprof → ICC`
**Когда:** первый раз для новой бумаги. **Время:** 20–60 минут.

### 📏 Только измерение

`chartread → colprof`
**Когда:** мишень уже напечатана.
**Что нужно:** папка с `.ti1` или `.ti2`.

### ⏩ Продолжить измерение

Продолжает прерванное. Программа сама ищет незавершённые профили в `profiles/`.
Если найдёт несколько — спросит, какой продолжать.

### ⚡ Улучшить (качество)

То же, что «Полный цикл», но с 1200+ патчами и перезаписью.
Создаётся новая папка с суффиксом `_<патчи>` (например, `LomondGlossy_1200`).

### 📊 Проверить точность + HTML

`profcheck` — ΔE готового профиля.

В журнале:

```
Peak ΔE2000: 3.2
Avg  ΔE2000: 0.8  ← в выборке (завышено)
RMS:         1.1
```

> ⚠️ Это **в выборке** — цифры завышены. Для честной оценки используйте
> **🎯 Честная точность**.

### 🎯 Честная точность (вне выборки)

Делит ваши измерения на две части: по одной строится профиль, на другой
считается ΔE. Профиль этих патчей не видел — цифры честные.

В журнале:

```
патчей: обучение 685, проверка 115
вне выборки (честно) ΔE2000: peak = ..., avg = ..., rms = ...
в выборке (для сравнения):   peak = ..., avg = ...
ошибка подгонки по avg: +0.18 ΔE2000
```

### 🆚 Сравнить два профиля

Показывает **точность каждого профиля** и **охват цветов** через `iccgamut`.

### 💾 Резервная копия профиля

ZIP-архив папки профиля → `<папка программы>\backups\<Бумага>_<дата>.zip`.

### 🔍 Проверить прибор

`spotread` — проверяет, подключён ли ColorMunki. Результат — 🟢 индикатор в шапке.

## 📊 Проверка точности

После проверки программа:

1. Запускает `profcheck`
2. Считает ΔE:
   - **Peak** — максимальная ошибка (идеально < 5)
   - **Avg** — средняя ошибка (идеально < 1.5)
   - **RMS** — среднеквадратичная
3. Генерирует HTML-отчёт с графиками
4. Спрашивает: «Открыть HTML-отчёт?»

**Интерпретация ΔE2000 (Avg):**

| Avg ΔE | Качество |
|---|---|
| < 0.5 | 🟢 Идеально |
| 0.5 – 1.0 | 🟢 Отлично |
| 1.0 – 2.0 | 🟡 Хорошо |
| 2.0 – 3.0 | 🟠 Приемлемо |
| > 3.0 | 🔴 Плохо, переделать |

**Где хранится отчёт:** `<папка профиля>\report_fit_YYYYMMDD_HHMMSS.html`
(и `report_cv_*.html` для честной точности).

## 🆚 Сравнение профилей

1. Нажмите **🆚 Сравнить два профиля**
2. Выберите первую папку профиля
3. Выберите вторую папку

В журнал выведется сравнение точности и охвата обоих профилей:

```
[1] ΔE2000: peak = ..., avg = ..., rms = ...
[1] охват (iccgamut): 907943.6
[2] ΔE2000: peak = ..., avg = ..., rms = ...
[2] охват (iccgamut): 912845.1
```

**Что это значит:**
- Если второй лучше — используйте его
- Если одинаково — не стоит переделывать

## 💾 Бэкапы

## 🔧 Драйвер ColorMunki (Zadig)

**Проблема:** Windows использует для ColorMunki драйвер HID (как для мышки).
ArgyllCMS не может с ним работать.

**Решение:** заменить драйвер на `libusb-win32` через Zadig.

### Что делать (5 минут)

1. Скачайте [Zadig](https://zadig.akeo.ie/)
2. Запустите **от имени администратора**
3. Меню **Options** → галочка **List All Devices**
4. Выберите **`colormunki (Interface 0)`**
5. В поле справа выберите:
   ```
   libusb-win32 (v1.4.0.0)
   ```
6. Нажмите **Install Driver** или **Replace Driver**
7. Дождитесь окончания (10–30 секунд)
8. Закройте Zadig и нажмите **🔍 Проверить прибор**

### Как понять, что сработало

- ✅ В журнале: «Прибор обнаружен и готов к работе»
- ✅ В шапке кружок зелёный
- ✅ В Диспетчере устройств появится `libusb-win32 devices → colormunki`

### Возврат родного драйвера

Если захотите снова использовать i1Studio:

1. Откройте Zadig
2. **Options** → **List All Devices** → выберите `colormunki (Interface 0)`
3. В поле драйвера выберите **HID (Microsoft)**
4. **Replace Driver**
5. Перезагрузите компьютер

Или через Диспетчер устройств: удалить устройство → отключить и подключить кабель.

### Если Zadig не помог

- **Прибор занят** — закройте i1Studio, Calibrite, X-Rite, DisplayCAL
- **Не хватает прав** — запустите Zadig от админа
- **Плохой кабель** — попробуйте другой USB-кабель / порт
- **Устаревший firmware** — обратитесь к производителю

## 🔑 Лицензия и активация

### Пробная версия

**5 запусков.** Каждый запуск — минус 1. Счётчик виден в шапке.

### Когда закончится

1. Откроется окно «🔒 Требуется активация»
2. **HWID** — уникальный код вашего ПК (пример: `1E8223D0336F7958`)
3. Отправьте HWID продавцу:
   - **📧 Написать продавцу** — готовое письмо
   - Или вручную: `voroshilov64221@gmail.com`
4. Получите ключ вида:
   ```
   PRINTER-A1B2-C3D4-E5F6
   ```
5. Введите ключ:
   - **📋 Вставить из буфера**
   - Или вручную
   - Или `Ctrl+V`
6. Нажмите **✅ Активировать**

### Статус после активации

```
✅ Лицензия активирована: Иванов Иван
```

Появится в шапке (зелёный).

### Где хранится ключ

**Реестр:**
```
HKEY_CURRENT_USER\Software\PrinterProfiler
  — license         ← ваш ключ
  — hwid            ← HWID
  — launches        ← счётчик (для trial)
  — license_cache   ← кэш активации
```

**Файл:** `%APPDATA%\PrinterProfiler\state.dat`

### Особенности

- Ключ привязан к HWID — на другом ПК не сработает
- Первая активация — через интернет
- После активации — работает офлайн 24 часа (кэш)
- Если интернета нет — работает офлайн, если активирован ранее

### Сбросить ключ

**⚙ Настройки** → **Лицензия** → **🗑 Сбросить ключ** — удаляет активацию.

## 🚨 Если что-то пошло не так

### Порядок действий

1. **Не паникуйте**
2. Посмотрите **журнал** в окне программы
3. Откройте лог-файл: `<папка программы>\logs\`
4. Если есть HTML-отчёт — посмотрите точность
5. Напишите продавцу: HWID + описание проблемы + последние строки журнала

### Типичные проблемы

**Прибор не найден**
- Проверьте Zadig
- Закройте i1Studio / Calibrite / X-Rite
- Переподключите USB-кабель

**Прибор занят другой программой**
- Закройте все программы, работающие с калибратором
- Перезагрузите ПК

**ArgyllCMS не найден**
- Проверьте путь в ⚙ Настройки
- Папка должна содержать `targen.exe`, `chartread.exe`, `colprof.exe`
- Скачайте заново: [argyllcms.com](https://www.argyllcms.com/)

**Принтер не появляется в списке**
- Установите `pywin32`: `pip install pywin32`
- Перезапустите программу
- Проверьте, что принтер установлен в Windows

**Печать мишени смещена**
- Проверьте, что бумага ровная
- Проверьте настройки размера (A4 / A3)
- Откалибруйте принтер в его свойствах

**Измерение прерывается**
- Не трогайте калибратор при измерении
- Проверьте USB-кабель
- Попробуйте другой порт

**ΔE слишком большой (> 3)**
- Увеличьте патчи (1200+)
- Проверьте, что бумага соответствует профилю
- Проверьте, что принтер не использовался 1+ дней
- Попробуйте протереть патчи от пыли

**Профиль не применяется в Photoshop / Lightroom**
- Установите профиль в Windows (ПКМ → Установить)
- Перезапустите Photoshop
- В диалоге печати выберите этот профиль для принтера

**Логи не сохраняются**
- Проверьте, что папка программы не только для чтения
- Запустите от админа
- Проверьте свободное место

**Обновление не находится**
- Проверьте интернет
- Возможно, обновлений пока нет
- Нажмите **🔄 Проверить обновления** ещё раз

**Ключ не активируется**
- Проверьте интернет
- Формат ключа: `PRINTER-XXXX-XXXX-XXXX`
- Ключ привязан к HWID — на другом ПК не сработает
- Если HWID изменился (сменили материнку) — напишите продавцу
